# 🕹️ jogo — Projeto da engine

> **A raiz do projeto da engine fica AQUI** (`project.godot`, `ProjectSettings/`, `.uproject` etc.). Engines exigem esta estrutura, por isso o código do jogo não é espalhado em outras pastas.

## Como criar
1. Crie o projeto da engine nesta pasta (ou abra e salve aqui).
2. Siga a estrutura sugerida em `SOURCE/03-tecnico/arquitetura-de-codigo.md`.
3. Exporte os dados de `SOURCE/04-dados-de-design/` para `data/` (ou leia direto).

## Regras
- Nenhum valor de balanceamento fixo no código.
- Cada feature tem uma cena de teste.
- Mudanças relevantes são registradas em `../_logs/changelog-ia.md`.
