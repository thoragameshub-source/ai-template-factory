# 🔍 Skill — Revisar Entrega

## Passo a passo
1. Abrir o rascunho e o cabeçalho de rastreabilidade (ou linha do manifesto, se for asset).
2. Aplicar `06-qualidade/checklist-revisao.md`.
3. Verificar: pilares, escopo, dados externos, licenças.
4. Registrar parecer.

## Formato do parecer
```
Parecer: APROVADO PARA REVISÃO HUMANA | DEVOLVIDO
Problemas:
- <item> — <o que corrigir>
Dúvidas:
- <pergunta>
```

## Regras
- Revisor ≠ autor. Nunca marcar `aprovado`.
