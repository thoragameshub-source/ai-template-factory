# 🔍 Skill — Revisar Entrega

> 📝 **Como preencher:** substitua o que está entre `< >` e apague as linhas de exemplo quando tiver o conteúdo real.

## Objetivo
Auditar o rascunho contra `04-qualidade/checklist-revisao.md` e decidir: **aprovar para revisão humana** ou **devolver com ajustes**.

## Passo a passo
1. Abrir o rascunho e o cabeçalho de rastreabilidade.
2. Conferir cada item do checklist (sim/não/n.a.).
3. Verificar fatos e números contra `fontes-de-verdade.md`.
4. Registrar parecer.

## Formato do parecer
```
Parecer: APROVADO PARA REVISÃO HUMANA | DEVOLVIDO
Itens com problema:
- <item> — <o que corrigir>
Dúvidas para o responsável:
- <pergunta>
```

## Regras
- Quem revisa **não** é o mesmo agente que produziu (ou refaz a leitura "do zero").
- Nunca marcar `status: aprovado`; isso é decisão humana.
