# 📝 Checklist de Revisão

## Design
- [ ] Atende a um pilar e ao escopo
- [ ] Casos de borda previstos
- [ ] Sem valores inventados

## Código
- [ ] Sem números fixos de balanceamento
- [ ] Testes passam
- [ ] Sem plugin proibido
- [ ] Performance dentro do orçamento

## Arte/Áudio
- [ ] Segue art-bible / direção de áudio
- [ ] Nome e formato corretos
- [ ] Origem e licença registradas
- [ ] Nada que imite obra ou marca existente

## Geral
- [ ] Cabeçalho completo
- [ ] Sem segredos ou dados pessoais
