# 💡 _propostas-source

Em modo **EXECUÇÃO**, o `SOURCE/` é somente leitura para agentes. Quando o agente identificar algo **errado, faltando ou desatualizado**, ele cria aqui uma proposta.

Fluxo: agente propõe → humano responsável avalia → se aceitar, **o humano** altera o SOURCE e apaga a proposta.

Use o arquivo `modelo-proposta.md`.
