# 🛠️ Skill — Implementar Feature

## Antes
1. Ler a spec da feature (`ARTEFATO/design/`), `arquitetura-de-codigo.md`, `engine-e-stack.md`.
2. Conferir os valores em `04-dados-de-design/`.

## Passo a passo
1. Criar teste/cenário de validação.
2. Implementar lendo dados externos (sem números fixos).
3. Rodar testes e abrir a cena de teste.
4. Gravar em `ARTEFATO/jogo/` e registrar em `_logs/`.

## Entrega
Código + cena de teste + nota de como validar (passos de 1 minuto).
